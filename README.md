# private-banking — policies

Privacy policy and terms of use for `private-banking`, a self-hosted personal
finance dashboard run by one person on one machine for their own accounts.

These pages exist because registering an application with a PSD2 account
information service provider requires a privacy URL and a terms URL. The
application itself is private and is not published here.

Every factual claim in the privacy policy was checked against the application's
source code.
